# cmux Shortcuts — macOS Defaults

Single static page listing default cmux keyboard shortcuts on macOS, with text search and filters.

- Live source: `index.html` (no build step, no dependencies)
- Data source: https://cmux.com/docs/keyboard-shortcuts (transcribed Sep 2026)
- Filters: text search, category pills, modifier keys (Cmd/Ctrl/Opt/Shift), hide-unbound toggle
- Unbound rows are actions cmux ships with no keys assigned

## Run locally

Open `index.html` in a browser, or:

```sh
python3 -m http.server 8000
```

## Deploy

Vercel treats this as a static site. No config needed.
